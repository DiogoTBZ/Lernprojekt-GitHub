# Lernprojekt-GitHub

Mit diesem Projekt übe ich, wie ich Aufgaben in GitHub organisiere. Dafür habe ich drei Issues erstellt, sie mir selbst zugewiesen und zum Lernprojekt-Board hinzugefügt.

## Was ist im Repository?

- `src/` ist für Beispielcode gedacht.
- `docs/` ist für die Projektdokumentation und den Ablauf für Feedback gedacht.

## So arbeite ich mit dem Board

Alle Aufgaben starten in **To Do**. Wenn ich mit einer Aufgabe beginne, ziehe ich die Karte nach **In progress**. Danach prüfe ich das Ergebnis in **Review**. Wenn alles passt, schreibe ich einen kurzen Kommentar, schliesse das Issue und verschiebe die Karte nach **Done**.

Die drei Aufgaben gehören zum Meilenstein **Projektsetup**. So sehe ich auf einen Blick, welche Aufgaben noch offen sind.
