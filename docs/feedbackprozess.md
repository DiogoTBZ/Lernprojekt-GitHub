# So läuft ein Code-Review ab

1. Wenn meine Änderung bereit ist, öffne ich einen Pull Request und verlinke das passende Issue.
2. Ich ziehe die Karte nach **Review**. Die Person, die meine Änderung prüft, schreibt ihr Feedback direkt in den Pull Request.
3. Falls etwas fehlt oder unklar ist, passe ich die Änderung an und bitte nochmals um eine kurze Prüfung.
4. Wenn alles passt, führe ich den Pull Request zusammen, schliesse das Issue und prüfe, ob die Karte in **Done** steht.
